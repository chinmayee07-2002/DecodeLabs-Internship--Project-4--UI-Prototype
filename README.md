  # Project 4 – Organic Food Delivery App Prototype

## Overview

This project was completed as part of the DecodeLabs UI/UX Design Internship Program.

The objective of Project 4 was to transform the high-fidelity UI screens created in Project 3 into a fully interactive prototype that demonstrates realistic user flow, navigation, and micro-interactions.

The focus of this project was on interaction design, usability, and creating a seamless user journey from product discovery to order confirmation.

---

## Project Objective

Create a living prototype that simulates the behavior of a real mobile application by connecting screens through interactions and transitions.

The prototype demonstrates:

- User navigation flow
- Smart transitions
- Interactive components
- Checkout journey
- Mobile-first interaction design
